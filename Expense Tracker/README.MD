# Expense Tracker Project

A simple Python-based Expense Tracker project that helps users record and manage their daily expenses.

## Features

- Add new expenses
- View all expenses
- Calculate total spending
- Simple menu-driven interface
- Beginner-friendly Python project

---

## Technologies Used

- Python
- Lists
- Dictionaries
- Loops
- Conditional Statements

---

## Project Description

This Expense Tracker allows users to store expense details such as:

- Date
- Category
- Description
- Amount spent

The data is stored temporarily using a Python list of dictionaries.
